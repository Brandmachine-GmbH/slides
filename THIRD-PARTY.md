## Fonts

Both ship in `src/engine/assets/fonts/`, under the SIL Open Font License 1.1, with their
licence texts beside them.

| Font | Licence | Reserved Font Name |
| --- | --- | --- |
| Inter | OFL 1.1 (`OFL-Inter.txt`) | none |
| Playfair Display | OFL 1.1 (`OFL-PlayfairDisplay.txt`) | **yes**, "Playfair Display" |

The variable `.woff2` files are unmodified upstream releases. The `.ttf` files under
`static/` are single-weight instances generated by `scripts/make-static-fonts.py`, which
Chromium embeds as small selectable vector fonts when exporting a PDF.

An instance is a Modified Version under OFL clause 3, so it may not carry a Reserved Font
Name. The serif instance is therefore written out as **DeckSerif**, with its name table
rewritten. `fonts-static.css` still declares `font-family: "Playfair Display"` and points at
that file, because a CSS family name is a local alias for matching and the restriction is on
the name inside the font software. Do not rename the file back.

Swapping in your own fonts is a matter of replacing these files and the `@font-face` rules in
`fonts-variable.css` and `fonts-static.css`, then updating the two families named in
`tokens.css`.
